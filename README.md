# Srilakshmi Narayan — Personal Portfolio

A cinematic, interactive personal portfolio showcasing my journey as a Computer Science and Engineering student specializing in Cybersecurity, along with my projects, technical skills, achievements, and interests.

The portfolio combines modern visual design, animations, and interactive elements to create an engaging experience for visitors.

## ✨ Features

### 1. Scroll-Driven Hero Section

The landing section introduces me through a cinematic portrait animation.

- Uses a scroll-based visual effect to create movement in the portrait.
- Introduces my name, academic background, and areas of interest.
- Includes quick navigation to my LinkedIn profile and resume.
- Designed to create an engaging first impression.

### 2. About Me

A dedicated section introducing my academic background, interests, and technical journey.

It highlights my interest in:
- Cybersecurity
- Computer Vision
- Generative AI
- Data Analysis
- Software Development

### 3. Interactive Projects Section

The projects section features a retro-computer-inspired interface.

- Visitors can interact with six keys on the computer.
- Each key displays different project-related information on the screen.
- The interface provides an interactive way to explore my projects instead of using conventional project cards.
- Projects demonstrate my experience with application development, AI, data visualization, and problem-solving.

### 4. 3D Tech Skills Orbit

The technical skills section presents technologies through an animated orbital layout.

- Technology cards move along elliptical orbital paths around a central portrait.
- Different orbital depths create a layered 3D-inspired appearance.
- Cards display technology logos for easy recognition.
- Hover interactions highlight individual technologies.

**Technologies showcased:**
- Programming: Python, C, Java, JavaScript
- Web Development: HTML5, CSS3, React
- AI and Data: Generative AI, LLMs, Prompt Engineering, Pandas
- Cybersecurity: CTF, TryHackMe
- Development Tools: Git, GitHub, VS Code
- Other Tools: Streamlit, MongoDB

### 5. Journey Section

A section presenting my academic and technical development, including learning experiences, certifications, and participation in technical activities.

It reflects my continuous effort to improve my knowledge through practical learning and project development.

### 6. Contact Section

Provides visitors with ways to connect with me and explore my professional profiles.

### 7. Interactive Portfolio Chatbot

The portfolio includes a chatbot to make exploring the website more engaging.

- Visitors can interact with the chatbot.
- It provides information about me and my portfolio through predefined responses.
- It acts as an additional way to explore my background, projects, and skills.

### 8. Resume Download

Visitors can access and download my resume directly through the portfolio.

## 🚀 Running the Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/srilakshmin249/srilakshmi-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd srilakshmi-portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
